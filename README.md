# ИИ Телефонная книга

Личная записная книжка деловых контактов с ИИ: поиск по смыслу, проверка и обновление контактов по интернету с источниками, фото из Google Картинок, разбор визиток и подписей, черновики писем.

Сейчас приложение работает как страница-артефакт в Claude (`index.html`). Этот репозиторий — основа для будущего сайта и мобильного приложения.

## Что умеет

| Функция | Как работает сейчас |
|---|---|
| Список и карточки контактов | Алфавитный указатель, фильтры по стране и тегам, история общения |
| Поиск по смыслу | «Кто у меня связан с биодизелем?» — ИИ ищет по должностям, отраслям, доменам почты, истории |
| Добавление из текста и фото визитки | ИИ раскладывает подпись письма или фото визитки по полям |
| Поиск в интернете по контакту | Google (запасной — DuckDuckGo) через браузер приложения Claude → ИИ выбирает страницы о человеке → сверяет с карточкой → предлагает обновления со ссылками на источники; ничего не меняется без подтверждения |
| Фото | Загрузка файла / вставка из буфера / выбор лица на снимке Google Картинок |
| Письмо с ИИ | Черновик с учётом должности, компании и истории общения; язык по стране |
| Дополнить базу | ИИ предлагает страну и отрасль для контактов, где их нет |
| Импорт / экспорт | CSV, Excel, vCard (Google Контакты, Outlook, телефон); экспорт в CSV, vCard, JSON |

## Принципы

- **Данные — только у владельца.** Контакты не хранятся в коде и никогда не коммитятся в этот репозиторий (см. `.gitignore`).
- **Только профессиональная информация.** Поиск в интернете собирает должность, компанию, рабочие контакты, профили, профессиональные новости. Домашние адреса, семья и личная жизнь не собираются.
- **Каждый факт — с источником.** Изменения в карточке применяются только после подтверждения.
- **Однофамильцы отсеиваются**: совпадение имени должно подтверждаться компанией, должностью, страной или доменом почты.

## Как устроено сейчас (артефакт Claude)

`index.html` — одна страница без сборки. Возможности платформы Claude, которые она использует:

| Возможность | Зачем | Что заменит в своём сайте/приложении |
|---|---|---|
| `db` | Хранение контактов (доступ только владельцу) | Supabase / Firebase / Postgres |
| `sample` | Запросы к Claude: поиск по смыслу, разбор визиток, сверка фактов, письма | Claude API (`claude-sonnet-5-5` / `claude-haiku-5-5`) на своём сервере |
| `mcp` → `host:claude_browser` | Браузер приложения Claude для Google и чтения страниц | Поисковое API (Google Programmable Search, Bing, SerpAPI) + серверное чтение страниц |
| `assets` | Хранение фото | Объектное хранилище (Supabase Storage, S3) |
| `downloads` | Экспорт файлов | Обычные скачивания |

## Дорожная карта: сайт и приложение

1. **Сайт (PWA).** Вынести логику из `index.html` в модули, заменить возможности Claude на свои сервисы (таблица выше), добавить вход (Google / почта). Сайт сразу устанавливается на телефон как приложение.
2. **Сервер.** Небольшой API: ключ Claude хранится на сервере, поиск в интернете — через поисковое API, загрузка фото с найденных страниц напрямую (без снимков экрана).
3. **Мобильное приложение.** React Native / Expo поверх того же API: импорт контактов телефона, звонок и WhatsApp/Telegram из карточки, скан визитки камерой.
4. **Дальше:** напоминания «давно не связывался», связи компания ↔ люди, синхронизация с почтой и календарём.
