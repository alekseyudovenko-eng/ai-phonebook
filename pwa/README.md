# AI Phonebook PWA (первый мобильный MVP)

Это отдельный самостоятельный PWA-клиент для Android и других современных браузеров. Он не меняет исходный Claude-артефакт в корне репозитория и пока не подключает его ИИ-функции.

## Что реализовано

- адаптивный интерфейс для телефона и рабочего стола, светлая/тёмная тема;
- установка на главный экран через браузер;
- список контактов, полнотекстовый локальный поиск, просмотр, добавление, редактирование и удаление;
- IndexedDB: контакты остаются на конкретном устройстве и доступны без сети;
- офлайн-кеш оболочки PWA;
- импорт JSON-резервной копии и простого CSV с русскими/английскими заголовками;
- экспорт JSON-резервной копии;
- очистка небезопасных ссылок и экранирование отображаемых значений.

## Развертывание

Размещайте содержимое каталога `pwa/` на HTTPS-хостинге (например, как каталог сайта на GitHub Pages). Service worker и установка PWA требуют HTTPS (localhost подходит только для локальной разработки). Для проекта GitHub Pages проверьте, что URL заканчивается на `/pwa/`; относительные пути манифеста и service worker рассчитаны на это размещение.

На Android откройте опубликованный HTTPS-адрес в Chrome и выберите меню ⋮ → «Установить приложение» или «Добавить на главный экран».

## Важные ограничения и данные

- Данные этой MVP хранятся только локально в браузере/на устройстве. Они не синхронизируются между устройствами и не попадают в Claude-артефакт.
- Очистка данных браузера может удалить контакты. Регулярно используйте «Экспорт» и храните JSON-файл в безопасном месте.
- ИИ-поиск, поиск фото/соцсетей, импорт адресной книги Android и серверная синхронизация пока не реализованы.
- До подключения серверной синхронизации не вводите данные, которые не хотите хранить на этом устройстве.

## Проверка

После публикации проверьте manifest в DevTools Application → Manifest, установку на Android, загрузку приложения в авиарежиме после первого визита, CRUD, поиск, экспорт и повторный импорт JSON/CSV.
